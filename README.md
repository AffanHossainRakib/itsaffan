## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML/CSS/JavaScript (for development)

### Installation

1. Clone the repository
```bash
git clone https://github.com/AffanHossainRakib/itsaffan.git
```

2. Navigate to the project directory
```bash
cd itsaffan
```

3. Open `index.html` in your browser
```bash
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html
```

Or use a local development server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

## 🎨 Theme Customization

The website supports both light and dark themes. CSS variables are used for easy customization:

```css
:root {
  --primary: #your-color;
  --primary-light: #your-color;
  /* Add more custom colors */
}
```
